# StellarCore

A futuristic dark-themed landing page for the Stellar blockchain ecosystem and token sale platform.

Designed for deployment on Netlify and optimized for modern browsers, StellarCore features an animated space background, smooth preloading effects, responsive UI components, and direct access to important Stellar ecosystem platforms.

---

# Live Project

**Website:**

`https://stellarcore.netlify.app`

---

# Features

## UI & Design

* Dark futuristic Stellar-inspired interface
* Animated starfield background
* Nebula glow effects
* Smooth preloader animation
* Glassmorphism cards and panels
* Fully responsive mobile layout
* Hover glow transitions
* Animated progress bar

## Token Sale Components

* Live token sale card
* Raised funds section
* Participant statistics
* Connect wallet button
* XLM ecosystem integration

# Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/stellarcore.git
```

## Open Project

```bash
cd stellarcore
```

## Run Locally

Open `index.html` directly in your browser.

# Deployment (Netlify)

## Method 1 — Drag & Drop

1. Open Netlify
2. Create new site
3. Drag the project folder into Netlify
4. Deploy instantly

## Method 2 — GitHub Integration

1. Push project to GitHub
2. Connect GitHub to Netlify
3. Import repository
4. Deploy automatically

# Customization

## Change Colors

Edit CSS variables:

```css
:root {
  --bg: #050816;
  --primary: #00e5ff;
  --secondary: #7b61ff;
}
```

## Update Token Sale Data

Modify:

```html
<div class="stat">
```

sections inside `index.html`.

## Add Wallet Integration

You can integrate:

* Freighter Wallet
* Albedo
* Stellar Wallet SDK
